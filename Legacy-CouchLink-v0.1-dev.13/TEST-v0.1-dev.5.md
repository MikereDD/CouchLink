# CouchLink v0.1-dev.5 — First Input Test

1. Start the Windows host and confirm the trusted Android session reconnects.
2. On Windows, click **ENABLE REMOTE INPUT**. It is intentionally locked after every host launch.
3. Drag one finger across the Android touchpad. The Windows pointer should move smoothly.
4. Tap the touchpad and test the dedicated left-click button.
5. Long-press the touchpad and test the dedicated right-click button.
6. Use the up/down scroll buttons in a browser or File Explorer.
7. Click **DISABLE REMOTE INPUT** and confirm the phone no longer moves or clicks the pointer.
8. Re-enable input, hold/drag if desired, then disconnect Wi-Fi or close the Android app. The host must release any held mouse button.

Known scope: keyboard input, two-finger scrolling, drag lock, sensitivity settings, and polished production touchpad gestures are not included yet.
