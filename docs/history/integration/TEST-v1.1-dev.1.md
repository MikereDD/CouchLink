# CouchLink v1.1-dev.1 Integration Test

1. Start the CouchLink Windows host and confirm its dashboard is listening.
2. Put the Android phone and Windows PC on the same LAN.
3. Install and open the Android debug build.
4. Confirm the Home screen finds the Windows host.
5. Enter the six-digit code shown by the Windows host.
6. Confirm the Android status changes to launcher host connected.
7. Test Steam, GOG, Xbox, EA, Ubisoft, Rockstar, Epic, and Amazon launch/focus actions.
8. Stop the Windows host and confirm Bluetooth touchpad and keyboard still work.
9. With the host offline, test that launcher tiles use the Bluetooth HID fallback.
10. Restart the Windows host and confirm the trusted session reconnects without a new code.
