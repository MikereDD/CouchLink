# Development History

This directory preserves build-specific notes without cluttering the active source roots. Files are retained for traceability and rollback.

- `android/` — Android Bluetooth-HID-only development notes, fixes, validations, release material, and manifests.
- `windows/` — Windows host refactor and platform-specific history.
- `integration/` — Combined Android/Windows integration snapshots and build fixes.

Current documentation lives at the repository root and under `docs/architecture`, `docs/building`, and `docs/release`.
