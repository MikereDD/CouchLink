# CouchLink Remote v0.2-dev.9 — Premium UI

## Visual upgrade

- Rebuilt the Home screen around the approved premium CouchLink design.
- Replaced the card-style header with the large CL mark, two-tone CouchLink wordmark, and illuminated Remote Ready status capsule.
- Added a metallic Bluetooth connection bar with a custom Bluetooth medallion and expandable connection details.
- Added letter-spaced LAUNCHERS and COMMAND DECK section labels.
- Restyled Steam as the dominant full-width launcher with cyan edge lighting and GOG Galaxy as the second full-width feature tile with violet edge lighting.
- Restyled Xbox, EA app, Ubisoft, Rockstar, Epic, and Amazon into a balanced 3-column metallic launcher grid.
- Rebuilt command controls with custom vector-style Alt-Tab, Task, Show, and Close glyphs.
- Rebuilt the fixed bottom navigation as a segmented metallic control bar with a raised active destination.
- Extended the same dark metallic surface treatment to reusable panels used by Keyboard and Settings.
