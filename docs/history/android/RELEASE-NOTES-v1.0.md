# CouchLink 1.0

CouchLink turns an Android phone into a persistent Bluetooth keyboard, mouse, and living-room launcher remote for Windows without requiring a Windows companion app, cloud account, custom driver, Test Mode, or disabled Secure Boot.

## Highlights

- Persistent Bluetooth HID keyboard and mouse connection
- Input at the Windows sign-in screen
- Touchpad, mouse buttons, scrolling, and drag lock
- Keyboard and Windows command shortcuts
- Dedicated launchers for Steam, GOG Galaxy, Xbox, EA app, Ubisoft Connect, Rockstar Games Launcher, Epic Games Launcher, and Amazon Games
- Premium dark CouchLink interface with brand-orange outlines and white launcher icons
- Automatic reconnect and hardened foreground-service behavior
- Validated text sequencing and paced HID keystrokes

## Requirements

- Android 9 or newer
- Android device with Bluetooth HID device support
- Windows computer with Bluetooth
