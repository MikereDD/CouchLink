## Final stable-source cleanup

After the successful pipeline validation, the stable source was cleaned without changing intended runtime behavior:

- replaced the deprecated Compose path calls with `quadraticTo()`;
- made the `DrawableRes` constructor-parameter target explicit;
- explicitly retained debug symbols for `libandroidx.graphics.path.so`, which was already being packaged unstripped;
- pinned the wrapper to Gradle `8.13`, the supported Gradle line for AGP `8.11.1`;
- added signing-certificate fingerprint enforcement;
- added source-manifest update and verification tools;
- added clean source-archive and release-document packaging.

Because these cleanup changes alter the exact source tree and Android build inputs, run the final `Build-Release.ps1` once from this stable source before uploading the public artifacts. The checksums generated by that final run are authoritative.

## Release hygiene

The stable source archive excludes signing keys, passwords, pairing tokens, local properties, logs, generated binaries, build directories, publish directories, IDE state, and machine-specific release output. The included `SOURCE-MANIFEST-v1.1.sha256` covers every distributed source file except the manifest itself.
