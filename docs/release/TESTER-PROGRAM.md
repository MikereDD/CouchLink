# CouchLink Tester Program

CouchLink testers can opt in through **Settings → App Updates → Test Builds** on Android or **About → Update channel → Test** on Windows.

## What testers receive

- Selected prereleases and release candidates
- The same HTTPS, exact asset-name, SHA-256, package, and signing-certificate verification used by Stable
- A one-click Return to Stable control
- A Copy Test Report control for useful bug reports

## Reporting a problem

1. Reproduce the updater problem.
2. Choose **Copy Test Report**.
3. Include what you expected, what happened, and the copied report.
4. Never include pairing secrets or private network credentials.

Internal micro-builds may remain private. Public testers receive selected builds that are useful to validate.
