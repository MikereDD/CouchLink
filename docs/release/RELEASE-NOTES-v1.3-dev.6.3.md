# CouchLink 1.3-dev.6.3 Release Notes

CouchLink 1.3-dev.6.3 is a visual-only Windows Host dashboard theme-unification build. The main dashboard now uses the same approved dark CouchLink language as the Audio Output popup.

## Changes

- Deep near-black gradient window background and layered dark cards.
- Shared rounded CouchLink button family with accent, secondary, destructive, hover, pressed, disabled, and keyboard-focus states.
- Dark custom scrollbars throughout the main dashboard.
- Custom dark startup checkboxes with orange checked state.
- Trusted devices displayed as rounded selectable cards with device name, identifier, paired timestamp, and orange selected state.
- Pairing, connected device, startup, endpoint, status, and last-event sections visually aligned with Audio Output.
- Responsive two-column layout, window resizing, commands, bindings, pairing, persistence, and networking are unchanged.
