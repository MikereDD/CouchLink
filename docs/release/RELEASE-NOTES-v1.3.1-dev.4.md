# CouchLink v1.3.1-dev.4 Test Build

This prerelease polishes the proven CouchLink updater experience.

## Highlights

- Download progress on Windows and Android
- Visible download, verification, permission, installation, and restart stages
- Cleaner in-app release notes
- Return to Stable for Test-channel users
- Copy Test Report for volunteer feedback
- Improved success and failure messaging

Stable remains the default channel. Test builds remain opt-in and retain all HTTPS, exact-asset, SHA-256, package, certificate, and version checks.
