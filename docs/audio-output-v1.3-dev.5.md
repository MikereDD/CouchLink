# CouchLink v1.3-dev.5 — Windows Audio Output Popup

- Adds a tray-menu **Audio Output** popup.
- Lists active Windows render endpoints and marks the current default.
- Supports one-click switching for all Console, Multimedia, and Communications roles.
- Adds Headphones and TV / Display favorites with edit and clear actions.
- Persists favorite endpoint IDs and friendly names in host settings.
- Keeps disconnected favorites visible as unavailable.
- Refreshes whenever the popup opens or regains focus.
