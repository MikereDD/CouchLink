# CouchLink v1.2-dev.3 TV Remote test checklist

1. Install the debug APK over v1.2-dev.2 without clearing application data.
2. Open **TV Remote** and confirm Abaddon reconnects automatically.
3. Confirm the status changes to **Connected** / **TV remote ready**.
4. Test D-pad Up, Down, Left, Right, and OK.
5. Test Home and Back.
6. Test Volume Up, Volume Down, and Mute.
7. Test Play/Pause, Rewind, and Fast Forward in a media app.
8. Test Menu, Guide, Channel Up/Down, Input, and Power individually; record controls the Hisense ignores.
9. Open **Settings → TV Remote** and confirm discovery, diagnostics, reconnect, manual address, and Forget TV are available there.

The first priority is stable navigation and volume. Input and power behavior may vary by TV firmware.
