# CouchLink v1.2-dev.6 — Premium TV Remote UI checklist

## Visual review

- [ ] TV Remote header matches the main CouchLink dark metallic language.
- [ ] Power medallion is clearly visible in Ready, Standby, and disabled states.
- [ ] System buttons use matching custom icons and readable semibold labels.
- [ ] D-pad directions and OK remain easy to hit one-handed.
- [ ] Volume, channel, Google Live, and playback controls remain legible at normal Android display scaling.
- [ ] Input selector feels integrated rather than like a generic Android dialog.
- [ ] HDMI 3 is visually identified as the Fire TV Stick source.
- [ ] Disabled controls remain visible without appearing active.
- [ ] Orange accents are controlled and consistent with the rest of CouchLink.

## Functional regression

- [ ] Input opens the premium source selector.
- [ ] HDMI 1 switches to HW4.
- [ ] HDMI 2 switches to HW5.
- [ ] HDMI 3 switches to the Fire TV Stick on HW6.
- [ ] Composite and TV/Antenna remain available.
- [ ] Home, Back, Settings, D-pad, and OK work.
- [ ] Volume Up, Mute, and Volume Down work.
- [ ] Channel Up, Google Live, and Channel Down work.
- [ ] One-minute rewind, Play/Pause, and one-minute fast-forward work.
- [ ] Power-off, Wake-on-LAN power-on, and reconnect work.
- [ ] Premium haptics and the power double-tap guard remain intact.
