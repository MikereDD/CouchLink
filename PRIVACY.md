# CouchLink Privacy

CouchLink does not require an account, does not include advertising, does not use analytics or telemetry, and does not send user data to a cloud service.

## Local connections

- Bluetooth permissions are used to operate the Android device as a local Bluetooth HID keyboard and mouse and to support Bluetooth pairing and discoverability.
- The optional Windows Launcher Host uses the local network for discovery, trusted pairing, heartbeat messages, launcher commands, and launcher-state feedback.
- Keyboard, touchpad, mouse, and sign-in input remain on the direct Bluetooth HID connection and are not routed through the Windows host.

## Stored data

CouchLink may store local preferences, device identity, and trusted-host pairing tokens on the participating devices. These values are used only to provide the app's local functionality.

CouchLink contains no cloud account system, remote relay, advertising SDK, analytics SDK, or intentional telemetry pipeline.
