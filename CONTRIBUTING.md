# Contributing to CouchLink

Thank you for helping improve CouchLink.

## Before submitting changes

1. Open or reference an issue describing the problem or feature.
2. Keep Android Bluetooth HID and Windows Launcher Host responsibilities separate.
3. Preserve Bluetooth fallback and local-only behavior.
4. Avoid adding cloud dependencies, telemetry, advertising, or unnecessary permissions.
5. Run the relevant build and integration checks in `docs/building/`.
6. Update documentation and the changelog when behavior changes.

## Code and repository standards

- Keep generated build output, signing keys, passwords, and local configuration out of commits.
- Use focused commits with clear messages.
- Preserve existing development-history documents rather than rewriting historical records.
- Do not add third-party artwork or branding without confirming its licensing and permitted use.
